# カメラの実装（課題）

- 参考動画 
https://www.youtube.com/watch?v=c9f8NEugEVQ

## やること
・2人のPlayerを常に映しておく
・二人の距離が近ければカメラはズームにして、遠ければ引きにする
・今後Player同士3D空間で戦うことになるため、それに伴いカメラも3Dで動かすようにする

## 実装手順

### Phase 1: 基盤構築
1. **CameraSettingsの完成**
   - 必要なパラメータの追加・調整
   - プロパティの整備
   - 設定値の妥当性チェック

2. **CameraManagerの基本構造**
   - Cinemachine Virtual Cameraの参照設定
   - Target Groupの初期化
   - プレイヤー管理用のリスト作成

3. **CharacterControllerとの連携確認**
   - BattleJudge経由でのプレイヤー取得テスト
   - PlayerIDによる識別機能の確認

### Phase 2: 基本機能実装
4. **プレイヤー登録システム**
   - RegisterPlayer/UnregisterPlayerメソッド
   - Target Groupへの動的追加・削除
   - プレイヤー数の管理

5. **中間点追従機能**
   - 2プレイヤーの中間点計算
   - カメラターゲットの更新
   - スムージング処理の実装

6. **距離ベースズーム機能**
   - プレイヤー間距離の計算
   - FOV値の動的調整
   - 最小/最大値の制限

### Phase 3: 3D空間対応
7. **Y軸追従機能**
   - 高度差の考慮
   - カメラ角度の自動調整
   - 上下移動への対応

8. **3D空間配置**
   - 奥行き方向の対応
   - 適切なカメラ距離の維持
   - 3D戦闘に適したアングル

### Phase 4: 安全機能・最適化
9. **衝突判定とエラーハンドリング**
   - 壁・障害物判定
   - null チェック
   - 異常値の補正

10. **パフォーマンス最適化**
    - LateUpdate()での更新
    - 不要な計算の削減
    - フレームレート独立

### Phase 5: デバッグ・調整
11. **デバッグ機能追加**
    - 距離・FOV値の表示
    - ターゲット位置の可視化
    - Inspector上での調整機能

12. **テスト・調整**
    - 各種シナリオでのテスト
    - パラメータの微調整
    - 動作確認

### Phase 6: 演出・拡張（将来対応）
13. **特殊演出システム**
    - 戦闘開始演出
    - 必殺技時の演出
    - KO演出

## 追加で必要な処理

### 基本機能
・CameraManagerでCharacterControllerのTransformを登録・追跡する仕組み
・2人のプレイヤー中間点計算と追従
・プレイヤー間距離に基づくFOV自動調整
・Cinemachine Target Groupの動的管理

### カメラ制御
・最小/最大ズーム距離の制限
・スムージング処理（急激な移動を防ぐ）
・カメラ角度の自動調整（高度差対応）
・画面境界からプレイヤーがはみ出さない保証

### 3D空間対応
・Y軸（高さ）方向の追従設定
・3D空間での適切なカメラ配置
・プレイヤーの上下移動への対応
・奥行き方向の移動に対するカメラ調整

### 安全機能
・壁や障害物への衝突判定
・カメラ位置の補正処理
・プレイヤーが存在しない場合のエラーハンドリング
・無効なターゲットの自動除去

### パフォーマンス最適化
・フレームレート非依存の更新処理
・不要な計算の削減
・LateUpdate()での位置更新

### デバッグ・調整機能
・プレイヤー間距離の表示
・現在のFOV値表示
・カメラターゲット位置の可視化
・設定値のリアルタイム調整

### 特殊演出（将来的な拡張）
・戦闘開始時のカメラ演出
・必殺技発動時のズーム効果
・KO時のカメラ演出
・リプレイ機能への対応

### エラーハンドリング
・プレイヤーオブジェクトの null チェック
・設定ファイルの存在確認
・Cinemachineコンポーネントの有効性確認
・異常値の検出と補正

### CharacterControllerとの連携
・PlayerIDを使ったプレイヤー識別
・BattleJudge経由でのプレイヤー取得
・プレイヤーのTransform情報の取得
・壁衝突時のカメラ演出連携（IsWallHittingプロパティ活用）

## 注意事項
- Phase 1-2を最優先で実装し、基本的な2プレイヤー追従を確立する
- 各Phaseの完了後は必ずテストを行い、次のPhaseに進む
- デバッグ機能は開発全体を通して活用する
- 将来的な拡張を考慮した設計にする
